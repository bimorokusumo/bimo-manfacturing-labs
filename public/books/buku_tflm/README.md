## 🌟 Fitur Unggulan Buku Digital

1. **Dual Reading Mode (Mode Ganda Fleksibel) - 50 Halaman Lengkap:**
   - **Mode 3D Flip Book (50 Halaman):** Animasi membalik lembaran kertas realistis (two-page spread pada desktop/tablet landscape, single page pada mobile), bayangan melengkung 3D, kontrol navigasi panah, slider 50 halaman cepat, dan **efek suara kertas membalik (Web Audio API Synthesizer)**.
   - **Membuka & Membalik Buku Langsung dengan Klik Halaman:** Pengguna cukup mengeklik di mana saja pada sampul depan (cover) untuk membuka buku, mengeklik halaman kanan untuk membalik ke halaman selanjutnya, atau mengeklik halaman kiri / sudut lipatan (*corner curl*) untuk kembali. Tidak wajib mengeklik tombol 'selanjutnya'.
   - **Mode Smart Continuous Reader (50 Halaman):** Mode membaca gulir terus-menerus (vertical scroll) dengan sticky chapter navigation (lompat ke 50 topik), reading progress bar, dan kenyamanan membaca cepat.
2. **Kurikulum Deep Learning (Mindful, Meaningful, Joyful):**
   - Mengintegrasikan 3 pilar: *Mindful Learning* (Berkesadaran), *Meaningful Learning* (Bermakna), dan *Joyful Learning* (Menggembirakan) serta siklus 3 tahap: *Memahami (Understand)*, *Mengaplikasikan (Apply)*, dan *Merefleksi (Reflect)*.
3. **Model Interaktif & Visual Konkret (Lebih dari 300 Gambar Otentik):**
   - **Virtual Arc Lab (Simulator Parameter Pengelasan SMAW):** Mengatur Ampere (50–180A), Travel Speed, dan Arc Length secara dinamis pada kanvas visual. Menghitung profil rigi las, penetrasi sambungan, Heat Affected Zone (HAZ), spatter, dan mendiagnosa potensi cacat las secara realtime.
   - **Simulator Jangka Sorong Presisi (Vernier Caliper 0.05 mm):** Menggeser rahang ukur dengan slider, pembacaan skala utama & nonius real-time, serta mode **Tantangan Uji Ketelitian** tebak ukuran.
   - **Interactive APD Welder Inspector:** Menginspeksi APD standar juru las (helm otomatis DIN shade 9-13, sarung tangan kulit, apron, safety shoes 200J, masker respirator fumes, ear plug) beserta standar industri dan potensi bahaya yang dicegah.
   - **Interactive 5R Workshop Audit Board:** Eksplorasi budaya industri Ringkas, Rapi, Resik, Rawat, dan Rajin dengan aksi nyata siswa di bengkel fabrikasi.
   - **Dekoder Elektroda AWS A5.1:** Membedah arti kode elektroda bersalut (E6013, E7016, E7018, E6010) secara visual.
   - **3D Defect Diagnostic Cards:** Kartu 3D flip interaktif dengan foto makro cacat las nyata (Porosity, Undercut, Slag Inclusion, Crack) lengkap dengan akar masalah dan solusi perbaikan menurut standar ISO 17637.
   - **Interactive Welder Career Ladder:** Peta karir juru las (Welder 1G–6G/6GR, Welding Inspector CSWIP/BNSP, Welding Engineer) dan Business Model Canvas (BMC) technopreneurship.
   - **Text-to-Speech (Fitur Bacakan Materi):** Pembacaan audio suara bahasa Indonesia untuk setiap bab.
   - **Kuis Formatif Interaktif Bab 1 - 5:** Kuis penilaian otomatis dengan umpan balik langsung di akhir setiap bab.
   - **Sertifikat Digital Kompetensi Siswa:** Terbitan resmi digital yang dapat diisi nama siswa dan dicetak / diunduh (PDF/Print) disahkan oleh Kepala Sekolah Dodot Yuliantoro, S.Pd., M.T. dan Bimoro Kusumo, S.Pd.

## 🚀 Cara Menjalankan

### Opsi 1: Menggunakan Script Otomatis
Buka terminal dan jalankan:
```bash
./buka_buku.sh
```
Browser akan otomatis terbuka menampilkan buku digital di `http://localhost:8000`.

### Opsi 2: Membuka Langsung File HTML
Klik dua kali pada file `index.html` atau buka melalui browser apa pun (Google Chrome, Safari, Microsoft Edge, Mozilla Firefox). Seluruh aset visual, audio synthesizer, dan skrip bekerja secara mandiri tanpa memerlukan koneksi internet (100% offline-ready).
